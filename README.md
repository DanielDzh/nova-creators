# NOVA — AI-блогери з характером

Mobile-first вітрина цифрових креаторів. Чотири віртуальні блогери з власним стилем, стрічкою, сторіз і живим чатом. Користувач знайомиться з персонажем прямо на сторінці й переходить у Telegram, щоб продовжити спілкування.

**Демо:** _посилання з'явиться після деплою_

## Можливості

### Hero

- Дві стрічки фото креаторів (портрети й пости) безперервно пливуть назустріч одна одній. На hover стрічка зупиняється, тап по фото відкриває профіль.
- «Живий» чат поверх стрічки: креатори по черзі «друкують» привітання. Тап відкриває профіль одразу на вкладці «Чат».

### Каталог

- На смартфоні coverflow-карусель: центральна картка попереду, сусідні зменшуються, повертаються в 3D і тьмяніють, усе прив'язано до пальця. На планшеті й десктопі сітка.
- Мінімальна картка: повне ім'я, тематика й кількість підписників, обличчя не перекрите текстом.
- М'яке свічення фону в кольорі креатора, який зараз у фокусі.

### Профіль

- Bottom sheet зі статистикою, біо й тегами. Закривається свайпом за ручку, кліком по фону або `Esc`.
- Вкладки «Стрічка» і «Чат».

### Сторіз

- Повноекранний перегляд з прогрес-барами, автоперемиканням і паузою на утриманні.
- Навігація тапами й стрілками, подвійний тап ставить лайк (з вібрацією на Android), свайп вниз закриває.

### Демо-чат

- Сценарний діалог з індикатором набору тексту та швидкими відповідями. Наприкінці пропонує продовжити розмову в Telegram.

### Telegram

- CTA «Перейти в Telegram» у шапці, hero, профілі, сторіз, чаті, фінальному блоці та в липкій панелі на мобільному.

### Деталі

- Анімації на [Motion](https://motion.dev), підтримка `prefers-reduced-motion`.
- Safe-area для iPhone, плавна прокрутка до якорів, тактильний відгук на тап.
- SEO та соцмережі: метадані, Open Graph і Twitter Card з обкладинкою, фавікон, PWA-маніфест, `robots.txt`, `sitemap.xml`, структуровані дані JSON-LD.

## Стек

- [Next.js 16](https://nextjs.org) (App Router), React 19, TypeScript
- [Tailwind CSS 4](https://tailwindcss.com)
- [Motion](https://motion.dev) для анімацій і жестів
- `next/image` (static imports, blur-плейсхолдери), `next/font` (Unbounded + Manrope з кирилицею)
- ESLint + Prettier (з `prettier-plugin-tailwindcss`)

## Запуск

Потрібні Node.js 20.9+ і pnpm.

```bash
pnpm install
pnpm dev        # http://localhost:3000
```

| Скрипт              | Що робить                             |
| ------------------- | ------------------------------------- |
| `pnpm dev`          | дев-сервер                            |
| `pnpm build`        | продакшн-збірка                       |
| `pnpm start`        | запуск збірки                         |
| `pnpm lint`         | ESLint                                |
| `pnpm format`       | Prettier: форматування всього проєкту |
| `pnpm format:check` | Prettier: перевірка без змін          |

## Структура

```
src/
├── app/                      # layout, сторінка, глобальні стилі, SEO-файли
│   ├── layout.tsx            # шрифти, метадані, viewport
│   ├── manifest.ts           # PWA-маніфест
│   ├── robots.ts, sitemap.ts
│   └── opengraph-image.png, twitter-image.png, favicon.ico, apple-icon.png
├── assets/creators/<slug>/   # avatar.jpg, post-1.jpg, post-2.jpg
├── components/               # секції та інтерактивні компоненти
│   ├── hero-*                # стрічка фото й живий чат
│   ├── creators-section      # каталог з coverflow
│   ├── profile-*             # контекст і bottom sheet профілю
│   ├── story-*               # сторіз і прогрес-бар
│   └── chat-demo             # сценарний демо-діалог
├── config/                   # налаштування без контенту
│   ├── site.ts               # назва, тексти, URL, Telegram
│   ├── motion.ts             # криві, пружини, пресети анімацій
│   ├── interaction.ts        # пороги свайпів, таймінги, coverflow
│   └── images.ts             # розміри аватарок і sizes
├── data/                     # контент: креатори, кроки, вкладки, навігація
└── lib/                      # чисті функції: coverflow, жести, чат, форматування, JSON-LD
public/                       # PWA-іконки
```

## Принципи коду

- Файли й папки в `kebab-case`, компоненти в `PascalCase`.
- Компоненти й функції стрілочні.
- Жодних інлайн-функцій у JSX: обробники оголошуються в тілі компонента, елементи списків винесені в окремі компоненти.
- Жодних магічних чисел у в'ю: таймінги, пороги, анімації, розміри та тексти живуть у `config/` і `data/`.
- Під час свайпу каруселі стилі пишуться напряму в DOM, без ре-рендерів React.

## Як додати креатора

1. Поклади зображення в `src/assets/creators/<slug>/`: `avatar.jpg`, `post-1.jpg` і `post-2.jpg` (пропорція 3:4).
2. Імпортуй їх у `src/data/creators.ts` і додай об'єкт у масив `creators`: ім'я, нікнейм, тематику, акцентний колір, пости та сценарій чату.
3. За бажанням додай його фото в стрічку hero в `src/data/hero.ts`.

Решта інтерфейсу підхопить нового персонажа автоматично. Зображення підключені через static imports: Next.js додає до URL хеш вмісту, тож після заміни файлу користувачі одразу бачать нову версію, а не закешовану.

## Деплой

Проєкт розрахований на [Vercel](https://vercel.com): імпортуй репозиторій, framework визначиться як Next.js, додаткових налаштувань не потрібно. Продакшн деплоїться з `main`, на кожен PR створюється preview.

## Гілки й коміти

- `main` — стабільна версія, з неї деплоїться продакшн.
- `develop` — інтеграційна гілка, сюди через PR вливаються `feat/*`, `fix/*`, `docs/*`.
- Коміти у форматі `type: module: опис`, типи `feat`, `fix`, `refactor`.
